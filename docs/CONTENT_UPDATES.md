# 月間活動予定と制作物の更新

確認済みの掲載内容を作業ブランチで変更し、PRでレビューを受けます。本番反映は責任者の公開承認後に行います。開発の流れは [AI_WORKFLOW.md](AI_WORKFLOW.md) を参照してください。

## 月間活動予定

1. 責任者が公開を承認した月間予定画像を、日付や時刻が読める解像度のままWebPに変換し、`public/schedules/YYYY-MM.webp` に置きます。年月はゼロ埋めし、例として2026年11月は `public/schedules/2026-11.webp` です。
2. [src/data/schedules.ts](../src/data/schedules.ts) の `schedules` に一月分を追加します。`month` は画像と同じ年月、`image.width` と `image.height` は画像の寸法、`venue` はその月の掲載場所です。会場の補足があれば `venueNote` に記入します。
3. `sessions` に画像にある開催予定を日付順に転記します。`date` は `YYYY-MM-DD`、`start` と `end` は日本時間の24時間表記 `HH:mm` です。同じ月は一件にまとめ、開催日時と場所のテキストを画像と照合します。
4. 記載漏れや不確かな予定がないことを確認し、公開予定のデータだけを追加します。今月のデータがない場合は準備中と表示され、掲載済みの月は年月選択から閲覧できます。今月分でも全回の予定時刻が経過すると、過去に掲載した予定として表示されます。
5. 開催場所・日時の変更や中止は [公式X](https://x.com/okadaiaistudio) で案内します。月間予定自体を改訂するときは、画像とテキストを同じPRで更新します。

## 制作物

1. 制作者の公開同意を得て、氏名・画像・公開リンクの掲載範囲と画像の利用権を確認します。
2. [src/data/projects.ts](../src/data/projects.ts) の `projects` に作品を追加します。`name`（作品名）、`description`（説明）、`category`（種別）、`creator`（公開用の制作者表記）、`url`（作品の公開URL）を設定します。個人制作・共同制作は `creator` で区別できます。
3. 画像を掲載する場合は `public/projects/` に置き、`image` に `src`（`/projects/...`）、`alt`、`width`、`height` を設定します。画像を省略すると作品名のカードが表示されます。公開リポジトリへのリンクを掲載する場合は `githubUrl` を指定します。

## PR前の確認

`npm ci`、`npm run typecheck`、`npm run build` を実行します。[READMEの静的出力確認手順](../README.md#検証と静的出力) に従い、PCとスマートフォンで更新したページを確認します。活動予定は年月選択・画像拡大・日時と会場・公式Xへのリンクを、制作物は画像・制作者表記・リンクを確認します。月間予定の切り替えを試す際は、ブラウザのテスト用時計を日本時間の月末・月初に合わせて確認できます。
